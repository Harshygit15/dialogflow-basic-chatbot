# Basic Dialogflow Chatbot

This repository contains a simple Dialogflow ES chatbot project.

## Features
- Default Welcome Intent  
- Name Query Intent (responds when user asks "What is your name?") and other questions like "What is your purpose?", "How can you help me?"
- Default Fallback Intent  

## How to Use
1. Download the ZIP file from this repository.
2. Open Dialogflow ES.
3. Go to: Settings (⚙️) → Export and Import → Import from ZIP.
4. Upload the ZIP to recreate the chatbot.
